# WeatherNow

Aplikasi informasi cuaca harian berbasis Flutter.

## Deskripsi
WeatherNow menampilkan informasi cuaca terkini berdasarkan nama kota yang dimasukkan pengguna.

## Fitur Utama
- Pencarian cuaca berdasarkan nama kota
- Tampilan suhu, kondisi cuaca, kelembaban, dan kecepatan angin
- Penanganan kondisi loading, berhasil, dan gagal

## Teknologi
- Flutter 3.47.1 / Dart 3.13.1
- Package: http ^1.2.2
- API: Open-Meteo (open-meteo.com) — gratis, tanpa API key

## Cara Menjalankan
1. Clone repositori ini
2. Jalankan `flutter pub get`
3. Jalankan `flutter run`
